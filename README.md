# Model for fetus classification to normal, suspect or pathological class

The goal of this project is to develop an accurate and reliable classification system that categorizes fetuses into three classes: **healthy**, **suspect**, and **pathological**. Early detection of potential health problems in pregnant women is crucial in order to take preventive measures and provide support in the early stages of pregnancy. The model is intended to support clinicians in making informed decisions by helping them analyze fetal health data and improve pregnancy outcomes. Ultimately, the purpose of the system is to reduce risks for both the mother and the newborn through timely recognition of potential complications and the provision of appropriate medical attention.
The implemented models are XGBoost, Random Forest and Support Vector Machine.  
Model performance is evaluated using the confusion matrix, sensitivity, accuracy, precision, specificity, and F1-score.
